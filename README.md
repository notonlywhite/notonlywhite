## English

### Hi, I'm Heiko 👋

I'm a software engineer based in Regensburg, Germany. I build distributed systems with **.NET / C#**, frontends with **React, Angular and Vue**, and run both **cloud-native**. I work with **AI agents** as a deliberate part of my development process.

Most of my work lives in my organisation, **[SmartSolutionsLab](https://github.com/smartsolutionslab)**.

#### 🔭 What I'm working on

| Project | What it is |
|---|---|

| [**yumney**](https://github.com/smartsolutionslab/yumney) | A PWA that extracts recipes from any URL using an LLM, with shopping lists and a step-by-step cooking mode |

| [**software-fabric**](https://github.com/smartsolutionslab/software-fabric) | A template for starting new solutions on this architecture |

#### 🧭 How I work

- **Domain-driven design** with value objects. Primitive types stay out of the domain model.
- **Architecture decision records.** Every decision is written down with its reasoning.
- **Spec-driven development.** Spec, then plan, then tasks, then tests (red first), then code.
- **AI agents with clear gates.** Agents deliver the work; human review and CI decide what ships.
